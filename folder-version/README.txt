GANGNAM OBJECT — 강남페스티벌 제품 디자인 포트폴리오
=====================================================

[폴더 구성]
index.html              페이지 본문
css/style.css           디자인(색, 글꼴, 레이아웃)
js/main.js              스크롤 3D 연출, 탭, 버튼 동작
js/model-viewer.min.js  3D 뷰어 라이브러리 (Google model-viewer)
media/object.glb        3D 모델 (다이얼 회전·아이콘 불빛용으로 파츠를 나눈 버전)
media/object-data.js    같은 3D 모델 (컴퓨터에서 바로 열 때용)
media/festival.glb      축제장 걷기 3D 공간
media/festival-data.js  같은 축제장 공간 (컴퓨터에서 바로 열 때용)
media/phone.glb         1인칭으로 손에 든 휴대폰 (다이얼은 페이지에서 붙임)
media/phone-data.js     같은 휴대폰 (컴퓨터에서 바로 열 때용)
assets/views.png        4면 렌더링 이미지

[여는 방법]
- 컴퓨터에서 확인: index.html 더블클릭 → Chrome 또는 Edge로 열기
- 웹에 올리기: 폴더 구조 그대로 전부 업로드 (index.html 위치 기준으로 경로가 연결됨)

[3D 체험 기능]
- 보라 다이얼을 돌리면 유리판이 시계 가장자리를 따라 이동 (유리판이 돋보기처럼 아래 시계 숫자를 확대)
- 실버 다이얼을 돌리면 아이콘 불빛이 한 칸씩 이동
- 링을 직접 잡고 돌리거나, 아래 ⟲ ⟳ 버튼, 또는 자동 회전 버튼 사용
- 다이얼을 직접 돌릴 때 딸깍 소리 + (휴대폰) 진동, '소리 켜짐/꺼짐' 버튼으로 끄기 가능
- 3D 체험란의 '프로그램 바로 보기' 버튼으로 바로 그 프로그램 아이콘 켜기
- 아이콘별 프로그램 이름·시간은 js/main.js 의 ICONS 목록에서 수정

[축제장 걷기 · 1인칭]
- '입장하기' → WASD(방향키) 이동, Shift 달리기, 마우스 시선, Esc 마우스 풀기
- 손에 든 휴대폰의 다이얼: 휠 또는 Q/E = 실버 다이얼(프로그램 선택, 유리판이 시작 시간으로), R/F = 보라 다이얼
- 클릭(또는 Space) = '선택한 일정'에 담기/빼기, Tab 또는 오른쪽 클릭 = 폰 들어 보기
- 담은 구역 위로 빛기둥이 솟고, 그 구역에 도착하면 '도착 ✓'
- 휴대폰: 왼쪽 조이스틱 + 화면 드래그, ⟲ ⟳ / '일정 담기' 버튼
- 시간이 겹치는 프로그램을 담으면 경고, 목록은 날짜별로 정리
- 화면 위 나침반이 담은 일정 중 가장 이른(아직 안 간) 프로그램으로 안내
- 스탬프 투어: 여섯 구역을 모두 들르면 메인 무대 위로 피날레 불꽃놀이
- 멀리서 구역(표지판)을 조준점으로 겨누고 클릭하면 바로 일정에 담기 · 휴대폰은 표지판을 탭
- 일정에 담은 구역은 바닥과 빛의 막이 빛나며 활성화
- 패션 런웨이에서 모델 3명이 워킹, 광장 단상 위에 비둘기 7마리
- 이스터에그: 패밀리 콘서트 무대 앞까지 가까이 가면 히든 무대가 시작돼요
- 프로그램 이름·날짜·시간은 js/main.js 의 ZINFO 목록에서 수정
